# The box model: my answers

## 1. Which element is the parent panel?
class="activity-panel">

## 2. Which CSS rule controls the space inside the panel border?
the padding property controls the space inside the panel border

## 3. Which CSS rule controls the space after each panel?
the margin controls the space after each panel

## 4. Why does the image use `width: 100%`?
the image use 'width: 100%' makes the image fill the content width that is available inside the panel.

## 5. Why can both panels use the same CSS?
both panels use the same CSS because they have the same parent element
